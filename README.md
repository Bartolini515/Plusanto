# Plusanto

Plusanto to aplikacja finansowa stworzona z myślą o prostym i bardziej świadomym zarządzaniu budżetem osobistym. Projekt został zaprojektowany wokół autorskiego algorytmu budżetowego opartego na rzeczywistych filarach finansowych wykorzystywanych w codziennym zarządzaniu pieniędzmi.

Celem aplikacji jest pomoc użytkownikom w budowaniu stabilnych nawyków finansowych poprzez automatyczne planowanie wydatków, organizację budżetu oraz lepszą kontrolę nad finansami. System analizuje dane użytkownika i pomaga tworzyć zrównoważony podział środków pomiędzy najważniejsze obszary finansowe.

## Funkcje

- Tworzenie i zarządzanie budżetem osobistym
- Autorski algorytm budżetowy oparty na filarach finansowych
- Organizacja wydatków i kategorii finansowych
- Analiza finansów użytkownika
- Skupienie na budowaniu zdrowych nawyków finansowych
